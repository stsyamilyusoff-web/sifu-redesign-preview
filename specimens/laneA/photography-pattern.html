Photography · the pattern

Formalises the founder-validated direction (assessment 2026-06-30): real human photography for human moments, one brand-tint system, data-viz stays illustration. Demos use labelled placeholders; production = real Sifututor people.

The rules

1
Photography = human moments only. emotional heroes (onboarding, milestones, profile heroes) + headshots + success moments. Data-viz, icons, and functional UI stay illustration.
2
Authentic, diverse, Malaysian. real-feeling students + tutors; idealized/cliché stock backfires (the Headspace lesson). Production uses curated photos of REAL Sifututor people, which feeds the trust story.
3
One treatment system. A = full-bleed + brand-tint gradient (default hero) · B = framed card (contained contexts) · C = duotone (off-brand photo rescue). The tint is what makes many photos read as one brand.
4
Framed to the system + legible. rounded corners, clear focal point, mobile crop, text always over the tint band (never raw photo), alt text + contrast checked.
5
Performance. optimized sizes, lazy-load below the fold; a hero photo never delays the four-state loading rules.
