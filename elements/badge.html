THE CONVENTION · red
inDrive #19: a solid RED dot top-right of the Safety button. The universal “unread” signal, but RED, which we banned everywhere (swapped red→amber). A red dot in a red-free app can read as “problem,” not “new.”
THE PRECEDENT · brand colour
Fresha #65: a count badge in Fresha’s brand PURPLE, not red. Proof that a badge doesn’t need to be red to read as “new”, any brand-colour dot on a monochrome icon reads as unread. We follow this with indigo.
DECISION · FOUNDER-LOCKED · indigo, not red
Use INDIGO #2B2FBE for the notification dot + count badge. It keeps the red-free discipline, reads clearly as “new” on our monochrome icons, and Fresha #65 proves a non-red badge works. Reserving red would be the one crack in a rule we’ve held everywhere else.
