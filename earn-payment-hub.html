TAP-AFFORDANCE LAW (kit-wide, founder-settled 07-Jul): a right chevron › NAVIGATES, a caret ⌄/⌃ EXPANDS in place - never mixed. OBJECT CARDS (2+ lines with an anchor figure, e.g. next payout) carry an INLINE chevron attached to the label text (Airbnb section grammar, founder-amended 07-Jul); circles are reserved for icon-BUTTONS in the header right slot (funnel, share, plus) - ALWAYS circled, 36px; the back arrow stays bare kit-wide (iOS nav chrome); in-ROW action glyphs stay bare (they belong to the row, not the chrome). Awaiting student groups carry NO subtotal - name + wait meta + Remind + caret only; per-class amounts live in the expanded rows. LIST ROWS and single-line row-cards carry the bare 16px grey chevron. ROWS NAVIGATE, HEADERS ACT: action glyphs never live inside rows - artifact screens (statements, receipts) carry the circled share in their own header. In-place actions (Remind) sit as labelled pills BEFORE the trailing mark. Money rows are TEXT-LED - no leading icon-chips (Fresha/UC/Airbnb row grammar; founder consistency catch 07-Jul). Feed/browse content cards carry NO mark - the whole card reads as tappable. The whole surface is always the tap target, never just the icon. Groups collapse to one row by default (auto-expand when 3 groups or fewer); tap the row toggles the class list. Controls live behind the HEADER FUNNEL (the wave-1 feed grammar): the sheet carries Sort (Longest wait default / Newest / Highest RM on awaiting; Newest / Highest RM on pending) and Student (single-select rows with counts; search appears past 8 students). REMIND = a wa.me deep link to that parent with a prefilled message (WhatsApp green + glyph signals the handoff; the app does NOT track delivery, so there is NO reminded state and NO rate limit - deliberate, founder 07-Jul). Escalation = a quiet footer text link after the last group ("Stuck past 7 days? Raise a ticket" - grey line, underlined brand action, opens the ticket flow); founder-picked option A over a card (07-Jul). No teach line, no stuck card.
