This is the Sifututor design system site: the record of the whole-app redesign, treated as software rather than a page pile.

**The atom is the screen.** Each screen gets one page holding everything about it: every state compared side-by-side with the live app, the design provenance (pinned/dropped references and what is Sifututor-original), links to the full mock and the reference board.

**Where things are:**
- **Tutor app · journey** - screens organized by the tutor's journey stages. The Participate stage is the pilot; other stages arrive in Phase 2.
- **Program** - progress in plain words, and what still needs design.

Everything on this site is generated from the design pipeline's data files - nothing is hand-maintained twice. Use the search (top) to find any screen.
