Every screen build **reuses** @sifu/ui components (ChipHero, FactChip, StatusPill and the rest) before inventing anything, and uses **no raw hex**: all colour through tokens. The canonical how-to for every tutor screen is the design-system source-of-truth document (02-architecture) in the design-system repo; the screen must match the published gallery.
