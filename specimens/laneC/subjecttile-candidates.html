SubjectTile · the illustrated subject-colour tile

Lane C candidate set. The hub already locked the imagery direction: real photography for PEOPLE, illustrated colour tiles for SUBJECTS (adapted from Urban Company), and subject tiles sit OUTSIDE the Phosphor icon tiers. DR-005's gates survive re-skinning: monogram whenever an icon would be unclear, colliding, or culturally loaded; religious and moral subjects are ALWAYS a monogram, never a symbol. This sheet decides the illustration-to-monogram balance, the colour mapping, and the tile ground.
Grounded in origin/main of sifututor_tutor: subjects are backend-owned, fetched at runtime from tutor/curricula → subjects[] {id, name}, English-first, deduped by name (per-level join). There is no hardcoded list; the tile map keys off subject_id with a never-blank fallback. The only live glyph is one generic SubjectIcon, greenfield otherwise. Illustrations in this sheet are simple flat stand-ins; final art is one commissioned set drawn to one weight.

Rules to ratify (say if any feels wrong)

1 · The DR-005 gate survives. Icon only when clear + distinguishable from siblings + culturally neutral; when in doubt, monogram. Pendidikan Islam, Pendidikan Moral, Tasawwur Islam, Sejarah, Sivik and all languages are monograms; never a religious or cultural symbol.
2 · Keyed by subject_id, never the name string (names vary EN/BM). Unmapped id → fallback tile (open-book mark, neutral slate family), so a new backend subject never renders blank.
3 · Sizes. 64 picker grid (label below, outside the tile) · 40 inline row · radius 14 (matches buttons/inputs). No other sizes.
4 · One commissioned art set. All illustrations drawn to one stroke weight and corner language; the flat stand-ins in this sheet define composition, not final art.
5 · Colour discipline. Family colours live ONLY inside the tile (ground + mark). They never colour text, pills, or buttons; fit green, flag amber, and action indigo remain the only UI status colours.
6 · One map everywhere. The same tile renders on picker, class cards, records, reports; no surface invents its own subject art.
